## 🛠 웅진컴퍼스 과제 테스트

> **요약:** 어떤 상황에서 어떤 문제가 발생했고, 어떻게 해결했는지 한 문장으로 요약합니다.<br />
> **배경:** 주니어가 작성한 코드라고 가정합니다.
---

### 1. 🔍 문제 (Problem)
- **증상:** 실제로 발생한 에러 메시지나 비정상적인 동작을 기술합니다.
- **영역:** (가독성 / 성능 / N+1 / 에러 처리 / 보안 / 설계 중 선택)
- **상세 내용:** * 어떤 비즈니스 로직에서 문제가 발견되었는가?
  * 사용자 환경이나 시스템에 어떤 영향을 주었는가?

### 2. 📝 원인 (Cause)
- **발생 위치:** (코드 / 쿼리 / 설계 / 설정 중 선택)
- **분석 내용:**
  * 왜 이런 문제가 발생했는지 근본 원인을 분석합니다.
  * (필요 시) 로그 분석 결과나 프로파일링 지표를 첨부합니다.
  * "기존 설계의 ~한 점이 ~한 상황에서 병목/오류를 일으킴"과 같이 기술합니다.

### 3. 🚀 개선안 (Improvement)
- **대안 제시:** 문제를 해결하기 위해 고려한 방법들 (Option A, B, C)
- **트레이드오프 (Trade-off):** * 각 대안의 장단점을 비교합니다 (예: 속도는 빠르나 메모리 사용량이 증가함 등).
- **선택 근거:** * 왜 이 대안을 최종 선택했는지 기술적 근거를 제시합니다.
